# Эхо-бот Вебхука

Этот проект представляет собой эхо-бота, который принимает вебхуки и отвечает им тем же самым сообщением. Он полезен для тестирования и отладки вебхуков.

## Быстрая настройка на Vercel

1. Склонируйте репозиторий на свой локальный компьютер.
2. Создайте новый проект на Vercel и свяжите его с этим репозиторием.
3. Настройте переменные окружения (если они нужны) в разделе настроек Vercel.
4. Разверните проект.
